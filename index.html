サポート

Jotteo（ジョッティオ）は、ペンで書くことを中心にした Windows 11 のノートアプリです。Microsoft Store で配布しています。

使い方はヘルプをご覧ください。

お問い合わせ

不具合の報告・ご要望・ご質問は、GitHub の Issue で受け付けています（GitHub のアカウントが必要です）。メールでのお問い合わせは受け付けていません。

Issue を作成する ・ これまでの Issue を見る

Issue は誰でも読めます。ノートの内容や個人情報は書かない・添付しないでください。不具合の報告では、次のことを書いていただけると助かります。

  • Jotteo の版（設定 > このアプリについて）
  • Windows の版と、PC の機種・ペン
  • 何をしたら、どうなったか（期待した動作）

よくある質問

ノートはどこに保存されますか？
この PC の中にだけ保存されます。外部へ送信されることはありません。アンインストールするとノートも消えるので、残したいノートは設定の「バックアップ」で .jotteolib ファイルに保存してください。

別の PC にノートを移せますか？
設定の「バックアップ」で作った .jotteolib ファイルを、別の PC の Jotteo で開くと復元できます。1 冊ずつなら .jotteo で書き出して取り込めます。

アカウントは必要ですか？
いいえ。アカウント登録もインターネット接続も要りません。

Support

Jotteo is a pen-first note-taking app for Windows 11, available on the Microsoft Store.

For how to use Jotteo, see the Help.

Contact

Please report bugs, request features or ask questions through GitHub Issues (a GitHub account is required). We do not accept inquiries by email.

Open an issue · Browse existing issues

Issues are public. Please do not post or attach the contents of your notes or any personal information. For bug reports, it helps to include:

  • Jotteo version (Settings > About)
  • Windows version, PC model and pen
  • What you did, what happened, and what you expected

FAQ

Where are my notes stored?
Only on your PC. They are never sent anywhere. Uninstalling Jotteo also deletes your notes, so use Backup in Settings to save a .jotteolib file of anything you want to keep.

Can I move my notes to another PC?
Open a .jotteolib file made with Backup in Settings in Jotteo on the other PC to restore it. To move a single notebook, export it as .jotteo and import it.

Do I need an account?
No. Jotteo needs neither an account nor an internet connection.
